# 개인사업자 세금 계산기

1인 사업자를 위한 종합소득세 · 부가가치세 모의계산기 + 신고 가이드.

## 구성
- **수입금액 집계** — 카드 / 지역화폐 / 계좌이체 / 현금 채널별 매출 합산, 공급가액·부가세 자동 분리
- **종합소득세** — 장부기장 / 추계신고, 근로소득 합산, 세율 구간 시각화
- **부가가치세** — 일반과세자 / 간이과세자
- **신고 가이드** — 연간 세무 캘린더, 홈택스 신고 순서, 기장의무 기준, 세율표

## 배포 (GitHub Pages)

1. 새 저장소 생성 후 `index.html` 업로드
2. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
3. 1~2분 후 `https://<사용자명>.github.io/<저장소명>/` 에서 접속

커스텀 도메인을 쓰려면 저장소 루트에 `CNAME` 파일을 만들고 도메인만 한 줄 적으면 됩니다.

## 특징
- 단일 HTML 파일 (빌드 도구·의존성 없음)
- 모바일 최적화 (터치 타깃 확대, iOS 자동 확대 방지, 반응형 테이블)
- 외부 의존성은 Google Fonts뿐 — 차단되어도 시스템 폰트로 정상 동작
- 브라우저 저장소 미사용 (입력값은 새로고침 시 초기화)
