📌 일반과세자는 1년에 2번(1월·7월), 간이과세자는 1번(다음해 1월) 신고합니다. 간이과세자는 연 매출(공급대가) 4,800만 원 미만이면 납부의무가 면제됩니다(신고는 필요). 간이과세자는 매입세액이 커도 환급받을 수 없습니다.

처음 신고하는 1인 사업자 로드맵 (근로소득 겸업 기준)

  1. 준비 (지금 바로): 홈택스 가입 + 공동/간편인증 등록 → 사업용 신용카드 등록(조회/발급 메뉴) → 사업용 계좌를 하나로 정해 매출·경비만 그 통장으로. 이것만 해두면 경비 증빙의 80%가 자동 수집됩니다.
  2. 평소 (매월 말 10분): 이 프로그램 집계 탭 기준으로 카드/지역화폐/계좌이체/현금 매출을 엑셀이나 메모에 월별 기록. 임차료·재료비는 반드시 세금계산서나 카드로 결제 (현금 주고 증빙 없으면 경비 인정 못 받음).
  3. 1월 (부가세): 홈택스 → 부가가치세 신고. 카드·현금영수증 매출은 자동으로 채워져 있음 → 계좌이체·현금 매출을 '기타매출'로 직접 추가 → 매입(경비) 자료 확인 → 제출. 간이과세자는 이것으로 1년치 끝.
  4. 5월 (종소세): 홈택스 → 종합소득세 신고 → 로그인하면 뜨는 '신고도움 서비스'부터 확인 — 내 안내유형(단순경비율/간편장부 등)과 국세청이 파악한 수입금액이 나옵니다. 여기 뜨는 숫자가 출발점.
  5. 근로소득 합산: 신고서 작성 중 '근로소득 불러오기'를 누르면 회사 연말정산 자료가 자동으로 들어옵니다. 사업소득과 합산되어 세금이 다시 계산되고, 회사에서 낸 세금(결정세액)은 기납부세액으로 자동 차감 — 직접 계산할 필요 없음.
  6. 사업소득 입력: 첫해 매출이 적으면 '모두채움/단순경비율'로 클릭 몇 번에 끝. 매출이 커졌다면(서비스업 7,500만↑) 복식부기 의무라 세무사 기장(월 10~15만)을 맡기는 게 가산세보다 쌉니다.
  7. 마무리: 지방소득세(소득세의 10%)는 마지막 화면에서 위택스 연계 원클릭 → 납부는 계좌이체/카드, 1,000만 원 넘으면 2개월 분납 신청 가능. 신고서 PDF는 꼭 저장(비자·대출 소득증빙으로 사용).
🧭 요약: 평소엔 기록만, 1월엔 부가세, 5월엔 종소세. 첫 신고가 불안하면 5월에 세무서 방문 신고창구나 국세상담센터(126)에서 무료로 도와줍니다. 첫해 한 번만 세무사에게 신고대리(건당 10~20만 원 수준)를 맡겨 구조를 익히는 것도 좋은 방법입니다.

홈택스 신고 순서 (종합소득세)

  1. 홈택스 로그인 → 세금신고 → 종합소득세 신고. 5월에 국세청이 보낸 신고안내문(카톡·우편)에서 내 안내유형·기장의무부터 확인
  2. 수입이 단순하면 모두채움 신고로 국세청이 채워준 금액 확인 후 제출 — 가장 간단
  3. 장부기장 시: 간편장부 작성분을 총수입금액 및 필요경비명세서로 입력, 복식부기는 세무대리인 조정 권장
  4. 추계신고 시: 업종코드 입력 → 단순/기준경비율 자동 적용
  5. 소득공제(인적공제·국민연금·노란우산) → 세액공제(자녀·전자신고 2만 원) 입력
  6. 지방소득세는 신고 마지막 단계에서 위택스 연계로 원클릭 신고
  7. 납부: 홈택스 계좌이체·카드 (1,000만 원 초과 시 2개월 분납 가능)
